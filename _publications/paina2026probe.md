ProbeBench (PROBE) measures how well coding agents discover bugs when auditing entire repositories. It compares agent findings with 2,457 bugs fixed by maintainers across 20 real repositories over the following 18 months. The benchmark studies the differences between the bugs agents report and those maintainers fix.

Explore the [live leaderboard and benchmark](https://probebench.com/) or read the [paper](https://arxiv.org/abs/2610.35987).
